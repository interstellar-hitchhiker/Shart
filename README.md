# SHART — Hashprint Studio

SHART started as a simple text-to-art experiment: type some text, generate a SHA-256 hash, and turn that hash into a repeatable abstract image.

## Version 1

* Turned text into a SHA-256 hash.
* Used the hash to place colours, shapes, and positions on a canvas.
* Same text always made the same image.
* Could download the result as a PNG.
* Fun idea, but mostly a visual demo.

## Version 2

Version 2 rebuilds the idea as a proper visual fingerprint tool.

* Cleaner, darker, more polished interface.
* Text-to-art mode for creating hash-based images.
* Compare mode to show how tiny text changes create huge hash changes.
* Avalanche meter showing how much the hash changed.
* File mode for drag-and-drop file fingerprinting.
* Multiple art styles instead of one basic shape system.
* Copy hash, export PNG, random phrase, mutation test, and local gallery.
* No server needed: everything runs inside one browser page.

## Purpose

SHART makes hashing visible. It turns invisible digital fingerprints into art, so users can see how sameness, change, and tampering work.
